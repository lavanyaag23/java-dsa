# Arrays in Java

This folder contains Java programs covering the fundamental concepts of Arrays in Java along with common array-based operations and matrix manipulations.

## Programs Included

### Intro.java

Introduction to arrays, declaration, initialization, and basic operations.

### ArraySum.java

Calculates the sum of elements present in an array.

### ArrayMax.java

Finds the maximum element in an array.

### ArrayReverse.java

Reverses the elements of an array.

### SubArray.java

Demonstrates generation and traversal of subarrays.

### TwoDArray.java

Introduction to two-dimensional arrays, element access, and traversal.

### TransposeMatrix.java

Computes the transpose of a matrix.

### RotateMatrix.java

Rotates a matrix by 90 degrees clockwise.

## Concepts Covered

* Array Declaration and Initialization
* Traversing Arrays
* Finding Maximum Element
* Array Reversal
* Subarrays
* Two-Dimensional Arrays
* Matrix Transpose
* Matrix Rotation
* Nested Loops

## Language

* Java
