# ArrayList in Java

This folder contains Java programs demonstrating the usage of **ArrayList**, one of the most commonly used dynamic data structures in Java.

## Programs Included

### Operations.java

Demonstrates common ArrayList operations such as:

* Adding elements
* Accessing elements
* Updating elements
* Removing elements
* Checking size

### RemoveEvenNo.java

Program to remove even numbers from an ArrayList using iteration and conditional logic.

## Concepts Covered

* Dynamic Arrays
* ArrayList Creation
* Adding and Removing Elements
* Traversing ArrayLists
* Updating Elements
* Basic Problem Solving with ArrayLists

## Language

* Java

## Learning Outcome

Through these programs, I learned how to:

* Use Java's ArrayList class
* Perform CRUD operations on ArrayLists
* Traverse and manipulate dynamic collections
* Apply ArrayLists to solve simple problems
